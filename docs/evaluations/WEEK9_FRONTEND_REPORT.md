## 3. UI 交互体验与安全审计特色
1. **脱敏与校对一体化**: 转写卡片默认仅展示经脱敏过滤的手机号及隐私信息，坐席可随时切换“编辑模式”修正标点，修改后自动标记“人工已修订”。
2. **知识出处透明溯源**: RAG 检索返回的条款带高亮卡片和置信度标签，帮助坐席在确认工单前精准核实依据，杜绝大模型胡言乱语。
3. **防误触双重保障**: HITL 确认建单后，按钮立即切换为禁用状态并展示工单号，同时下发幂等键，杜绝坐席连续点击造成的重复派单。
